## Overview of Federal API Requirements

Most U.S. Government data endpoints integrated into this application are **publicly accessible open data endpoints** that require no authentication.

### Endpoint Authentication Matrix

| Federal Data Endpoint | API Key Required? | Notes |
| :--- | :--- | :--- |
| **ClinicalTrials.gov** | **No** | Public API v2 (No key required) |
| **USASpending.gov** | **No** | Public API v2 (No key required) |
| **arXiv Repository** | **No** | Open OAI-PMH & Search API |
| **USPTO Patents & PatentsView** | **No** | Public Open Data endpoints |
| **SEC EDGAR Filings** | **No** | Requires standard `User-Agent` header (`Name/1.0 email@domain.com`) |
| **openFDA** | **Optional** | Public endpoint works keyless; optional free key unlocks 240 req/min |
| **SAM.gov Solicitations** | **Optional** | Ingests fallback public signals; optional key unlocks direct SAM.gov API access |

### Getting Optional Keys & SAM.gov Unique Entity ID (UEI)

- **openFDA**: Visit [open.fda.gov/apis/authentication](https://open.fda.gov/apis/authentication/) to get an instant key via email in 10 seconds.
- **SAM.gov Public API Key**: Visit [open.gsa.gov/api/get-opportunities-public-api](https://open.gsa.gov/api/get-opportunities-public-api/) or [sam.gov](https://sam.gov/) and sign in with Login.gov to generate a Public API Key under Account Settings.
- **SAM.gov Unique Entity ID (UEI)**: Received via SAM Entity Management workspace (e.g. `LX7PJGDDUUU1` for `UNCLE ROBERT CONSULTING`).

> **GSA API Gateway Key Propagation**: Newly generated SAM.gov Public API Keys (e.g., `SAM-007a9afa-a177-4e68-8a71-be3ad125e71f`) undergo a propagation period of up to **24 hours** across GSA's API Gateway clusters. During this window, `api.sam.gov` endpoints may return HTTP 404 or 403. The platform automatically verifies key registration and seamlessly uses **USASpending.gov API** with your Unique Entity ID (`LX7PJGDDUUU1`) for live contract and award data until SAM.gov Gateway sync completes.
